Hey team! 🚀 Most AI tools are just web apps that don't get mobile. So I built **Everything Claude Code Mobile** — a plugin that transforms Claude Code into a mobile specialist that actually speaks our language.

Want to add a feature? `/mobile-plan` breaks it down with proper architecture. Gradle exploding? `/gradle-fix` handles it. Need tests? `/mobile-tdd` **forces** you to write them first (80% coverage enforced). It's got 20+ specialized agents for Android, iOS, and KMP — from Compose state hoisting to Swift Combine patterns to shared model design. It even learns your team's conventions over time.

**Free, open source, stupid easy to install.** Check it: https://github.com/ahmed3elshaer/everything-claude-code-mobile ⚡
